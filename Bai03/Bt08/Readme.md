# Bài 08 - Thực hành module fs trong Node.js

## 1. Giới thiệu
Sử dụng module fs trong Node.js để thực hiện các thao tác với tập tin và thư mục.

## 3. Các chức năng thực hiện
- Tạo thư mục data bằng fs.mkdirSync().
- Tạo tập tin ghichu.txt.
- Ghi ít nhất 3 dòng nội dung vào tập tin.
- Đổi tên ghichu.txt thành ghichu_moi.txt bằng fs.renameSync().
- Đọc và hiển thị nội dung tập tin ghichu_moi.txt.
- Tạo tập tin tam.txt.
- Xóa tập tin tam.txt bằng fs.unlinkSync().
- Hiển thị thông báo sau mỗi thao tác.
